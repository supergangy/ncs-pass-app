# 앱 — 설치형 웹앱(PWA)

한 문제씩 골라 푸는 화면이다. **문항은 앱 안에 들어 있고 서버에 물어보지 않는다.**
분석한 한국사 앱(`com.odapnote.hangooksa`)과 같은 판단이다 — 지하철에서 풀려야 한다.

```bash
python tools/export_bank.py     # 문항 → data/bank.json · data/admin.json
```

그 다음 아무 정적 서버로나 `app/` 을 열면 된다. `file://` 로는 안 된다 —
`fetch` 가 막히고 서비스 워커도 안 붙는다.

```bash
python -m http.server 8777 --directory app
```

> 위 경로는 **원본 저장소(`ncs-exam`) 기준**이다. 배포 사본에서는 파일이 루트에 있으므로
> `--directory .` 로 연다. 아래 「배포」 참고.

## 무엇이 어디에 있나

| 파일 | 하는 일 |
|---|---|
| `index.html` | 껍데기. 상단 막대 · 본문 · 하단 탭 |
| `app.js` | 전부. 저장소 · 데이터 · 해시 라우터 · 화면 17개 |
| `app.css` | 모바일 우선. 다크 모드는 `prefers-color-scheme` 로 따라간다 |
| `data/bank.json` | **학습자가 받는 것.** 540문항 · 1,013KB |
| `data/admin.json` | **관리자 모드에서만 받는다.** 위험도 · 출제이유서 · 379KB |
| `sw.js` | 서비스 워커. 껍데기와 `bank.json` 을 캐시에 넣어 오프라인으로 만든다 |

## 두 파일로 나눈 이유

위험도(`low`·`mid`·`high`)와 출제이유서는 **출제자용**이다. 학습자 화면에 나오면
정답의 확실성이 새어 나가고(「high 니까 이 문제는 시비가 있겠군」) 함정 설계도 드러난다.

그래서 `bank.json` 에 **아예 넣지 않았다.** 관리자 모드를 켤 때만 `admin.json` 을
따로 받아 온다. 평소에는 내려받지도 않는다.

**다만 이것은 보안 장치가 아니다.** 주소를 아는 사람은 `data/admin.json` 을 직접 열 수 있다.
브라우저에서 도는 것에 진짜 접근 통제를 걸려면 서버가 필요하다.
지금 목적은 「보통 사용자에게 보이지 않게」이지 「누구도 못 보게」가 아니다.

관리자 암호는 `ncsbank` 다. 바꾸려면 `app.js` 의 `ADMIN_HASH` 를 새 SHA-256 으로 바꾼다.

```bash
python -c "import hashlib;print(hashlib.sha256(b'새암호').hexdigest())"
```

## 화면

```
홈 · 회차 · 복습 · 오답 · 더보기
                        └ 검색 · 키워드 · 북마크/확인필요 · 통계 · 설정
```

### 들어가는 길 네 갈래

```
회차 ──── r1~r5 (200)   시간을 재고 실제 시험처럼
직렬 ─┬─ 전산직 (150)  ─ 8과목 ─ 유형 62종
      └─ NCS   (390)  ─ 8영역 ─ 유형 128종
키워드 305개            과목을 가로질러 묶는다
검색                    발문·선지·유형·키워드·자료·지문·해설·단평 전부
```

`직렬 → 과목 → 유형` 이 기본 길이고, 키워드와 검색이 그 위를 가로지른다.
「교착 상태」를 누르면 운영체제와 데이터베이스론 문항이 함께 나온다.

## 회차 모드 — 낱개 풀이와 규칙이 다르다

| | 낱개 풀이 | 회차 |
|---|---|---|
| 채점 | 한 문항씩 즉시 | **제출해야** 한다 |
| 정답 | 바로 보인다 | 푸는 동안 **안 보인다** |
| 시간 | 없다 | 회차 사양대로 (1·5회 60분 · 2~4회 35분) |
| 이동 | 앞으로만 | 이전·다음 + **OMR 답안지**로 점프 |
| 표시 | — | **별표**(나중에 볼 문항) |

지켜야 했던 것 세 가지.

- **타이머는 마감 시각(`endsAt`)으로 잡는다.** 남은 초를 깎아 내리면 앱을 내렸다
  켤 때 시간이 되살아난다. 벽시계 기준이어야 백그라운드로 가도 맞다
- **중단하고 나가도 이어진다.** 진행 상태가 `sit` 에 남는다. 회차는 한 번에 하나만
- **제출할 때 비로소** 채점하고 `att` 에 기록한다. 중간에 나간 것이 오답이 되면 안 된다

제출하면 회차 오답이 **오답노트와 복습에도 들어간다.** 회차만 따로 놀면
거기서 틀린 문제가 복습에 안 뜬다. 답하지 않은 문항은 **오답으로** 센다 — 시험이 그렇다.

### 문항 번호는 인쇄본과 같다

`export_bank.py` 가 `config.py` 의 `AREAS` **선언 순서**로 읽는다.
`build.py` 의 `load_blocks` 와 같은 순서다. 알파벳순으로 훑으면 앞으로 파일 이름을
다르게 붙인 회차에서 **번호가 조용히 어긋난다.** 문항 수도 `AREAS` 기대값과
대조해 다르면 멈춘다.

## 북마크와 「확인 필요」

문제 화면 위쪽 **☆ 북마크** / **⚑ 확인 필요**(메모). `더보기 → 북마크·확인 필요`
에서 모아 보고 `marks-YYYYMMDD.json` 으로 내보낸다.

이상한 문항을 발견했을 때 **적어 둘 곳**이다. 내보낸 파일에 문항 id·과목·유형·
발문 앞부분·메모가 들어가므로 그대로 넘기면 무엇을 고쳐야 하는지 읽힌다.

## 사용자 기록

`localStorage` 의 `ncsbank.v1` 한 칸에 들어간다. **서버로 올라가지 않는다.**

```js
{ att:   { "문항id": [{c:고른선지, k:맞음, t:시각, m:걸린ms}] },
  srs:   { "문항id": {e:난이도계수, i:간격일, due:다음시각} },
  exams: { "r4_korail": [{at, score, n, sec, auto, ans:{번호:선지}}] },
  sit:   { tag, at, endsAt, ans, flag, at_no } | null,   // 응시 중인 회차 하나
  mark:  { "문항id": {b:북마크, f:확인필요, memo, at} },
  admin: false }
```

콘텐츠와 기록을 섞지 않는다. `bank.json` 을 새로 배포해도 기록은 그대로 남는다.
복습은 SM-2 를 줄인 것이다 — 맞히면 1 → 3 → 간격×계수로 벌어지고,
틀리면 0 으로 돌아가 10분 뒤 다시 나온다.

## 콘텐츠를 새로 배포할 때

1. `python tools/export_bank.py`
2. `sw.js` 의 `VERSION` 을 올린다 — 안 올리면 옛 캐시가 계속 나간다
3. 배포

## 오프라인 — 확인했다

**서버를 내려도 문항이 전부 뜬다.** 2026-08-14 데스크톱 크로미움에서 확인했다.

이전 판 문서는 「미리보기 브라우저가 서비스 워커를 막아 둔 것으로 보인다」고
남겨 두었는데, 다시 재 보니 정상이었다. 넷 다 확인한 것이다.

- `navigator.serviceWorker.controller` 가 `null` 이 아니다 — 페이지를 워커가 잡고 있다
- 활성 워커 상태가 `activated`
- `ncsbank-v9` 캐시에 **9개**가 다 들어왔다 — 껍데기 8개 + `bank.json`
- 정적 서버를 **완전히 죽인 뒤** 전체 새로고침 → 부팅 화면이 걷히고 문항이 나온다

네트워크가 정말 끊긴 상태였는지도 갈라서 확인했다. 캐시에 없는 주소
(`data/bank.json?nocache=…`)는 `Failed to fetch` 로 죽고, 같은 순간
`data/bank.json` 은 200 으로 나온다 — 서버가 아니라 캐시가 내주고 있다는 뜻이다.

### 아직 남은 것 — 휴대폰 설치

확인한 것은 **데스크톱 브라우저의 오프라인 동작**이다.
홈 화면에 설치한 뒤 비행기 모드에서 푸는 것은 안드로이드·iOS 실기기에서 따로 봐야 한다.
iOS 사파리는 캐시 용량 정책이 달라 1MB 짜리 `bank.json` 이 밀려날 수 있다.

다시 확인할 때는 이렇게 본다.

```
개발자도구 → Application → Service Workers   : 상태가 activated and is running 인가
개발자도구 → Application → Cache Storage     : ncsbank-v9 안에 9개가 들어왔나
개발자도구 → Network → Offline 체크 후 새로고침 : 화면이 그대로 뜨나
```

안 되면 이 문서 위쪽 「무엇이 어디에 있나」의 `sw.js` 부터 다시 본다.
`VERSION` 을 올리고 배포했는데 옛것이 나오면 캐시 이름이 안 바뀐 것이다.

## 오답노트 PDF

`오답` 탭 → 「PDF 용으로 내보내기」 → 내려받은 파일을 넣는다.

```bash
python tools/wrongnote_pdf.py wrongnote-20260806.json
python tools/wrongnote_pdf.py --ids major-csdb-common-003,r4_korail-06
python tools/wrongnote_pdf.py --risk high      # 검토용 — high 25건을 통째로
```

파이프라인을 새로 만들지 않았다. `build.py` 를 불러 해설지 서식(`solution.html.j2`)
그대로 굽는다. `marks-*.json` 도 같은 도구가 받는다.

`supergangy/ncs-exam-app` 공개 저장소에서 GitHub Pages 로 나간다.


**이 저장소는 `ncs-exam/app/` 의 사본이다.** 원본은 private 저장소 `supergangy/ncs-exam` 이고
문항·빌드 도구(`tools/`·`config.py`·`build.py`)가 거기 있다. 여기 있는 것은
Pages 가 루트를 서비스하도록 `app/` 안쪽만 떼어 올린 것이다 —
그래서 위 명령들의 경로(`tools/export_bank.py`)는 **원본 저장소 기준**이다.

고칠 때는 원본에서 고치고 이쪽으로 올린다. 이쪽만 고치면 다음 배포에 덮인다.

## Flutter 판과의 관계

이 화면은 **`mobile/` 의 Flutter 앱으로 이미 옮겨졌다** (v1.5.1 · 2026-08-12).
APK 는 GitHub Releases 에 올라간다. 화면 16개·저장 형식·SM-2 간격·검색 로직을
웹판과 1:1로 맞춰 둔 것이므로, **한쪽 로직을 고치면 다른 쪽도 같이 고친다.**
v1.5.1 의 이중 이스케이프 수정이 `lib/text.dart` 와 `app/app.js` 양쪽에 들어간 것이 그 예다.

`bank.json` 은 두 판이 그대로 공유한다. 판올림은 `mobile/CHANGELOG.md` 를 본다.

### 1:1 에서 뺀 것

규칙을 어기는 것이 아니라 **범위를 좁힌 것**이다. 아래는 앱에만 있다.

| 기능 | 웹에 없는 이유 |
|---|---|
| 복습 알림 | PWA 알림은 iOS 제약이 커서 1:1 대응이 깨진다 |
| 회차 「PDF로 풀기」 | 문제집 PDF 4.5MB 를 웹에서 내려받게 할 수 없다 |
| **회차 필기** (v1.8.0) | PDF 모드 위에 얹는 것이라 위 항목에 딸린다 |

필기는 **백업 JSON 에도 넣지 않는다.** 한 회차가 MB 라 기록의 수십 배이고,
웹판이 받아도 쓸 데가 없다. 기기에만 남는다 — 폰을 바꾸면 필기는 따라오지
않는다는 뜻이다.
